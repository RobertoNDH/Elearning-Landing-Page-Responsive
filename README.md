# 📘 Elearning Landing Page Responsive

A fully responsive and modern landing page for an e-learning platform.  
This project focuses on clean UI, scalable front-end architecture, and mobile-first development.

---

## 🚀 Features

- Fully responsive layout (mobile → desktop)  
- Modern and clean UI  
- Organized structure with HTML, CSS/Sass  
- Reusable components and utility classes  
- Optimized images for different screen sizes  
- Smooth gradients, buttons, and polished design

---

## 📚 What I Learned

- Mobile-first responsive design

- Semantic and accessible HTML structure

- Component-based CSS organization

- Image optimization for different screen sizes

- How to build a modern landing page structure

- CSS3
